# Licence notes

## Conclusion

The original author has given public permission to update the mod, and the source code is under
**CC BY-NC-SA 4.0**. No further confirmation is needed. This port is released under the same
licence and meets its conditions:

- **BY** (attribution): the original authors are credited in README.md, LICENSE, the in-game mod
  credits (`neoforge.mods.toml`) and the mod's author field. The jar carries LICENSE, README and
  CHANGES.
- **NC** (non-commercial): no paid access, no ad-gated or monetised downloads, no paid-only builds.
- **SA** (share-alike): the port is CC BY-NC-SA 4.0 too.
- **Changes indicated**: CHANGES.md lists everything that differs from the original.

Note: CC BY-NC-SA is not an OSI software licence and is incompatible with GPL/MIT code being mixed
in. Keep any third-party code out of the project unless its licence permits that.

uploaded jars; the author's own description explicitly licenses the source code under
CC BY-NC-SA 4.0 and invites updates, which is what this port is built from.

Team listed on the page: Funwayguy (owner); GenDeathrow, thislooksfun1 and Timbucktato (authors).
