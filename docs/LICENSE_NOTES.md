# Licence notes

Checked 2026-11-25 against a read-only clone of https://github.com/EnviroMine/EnviroMine-1.7
(default branch, last commit `1652062` on 2015-12-07 by Funwayguy: "Fixed config crash in previous
experimental build").

## What the repository says

- `LICENSE` (14,702 bytes): the full legal code of **Creative Commons
  Attribution-NonCommercial-ShareAlike 4.0 International Public License**. It is the unmodified
  CC text; it names no copyright holder and adds no extra terms.
- `README.md`, section "Licence": `CC BY-NC-SA 4.0`, with links to the human-readable deed and the
  legal code. (The badge image it shows is the 3.0 badge, but the text and links say 4.0.)
- No per-file licence headers were found in the Java sources.

## Conflicts elsewhere

- The original CurseForge project page's licence field says "All Rights Reserved", while its
  description says the source is CC BY-NC-SA 4.0 (per the brief; not re-checked here).
- EnviroMine Lite's Modrinth page lists CC-BY-NC-SA-4.0 and links to the same 1.7 repository.

## Working assumption until the authors confirm

Treat the code as CC BY-NC-SA 4.0, as the repository's own LICENSE file states:

- **BY**: credit the original EnviroMine team (Funwayguy, who made the last commit, plus the other
  authors; the full list still needs to be taken from the full commit history and the CurseForge
  project members before release, since the reference clone is shallow) in README.md, LICENSE and `neoforge.mods.toml` credits.
- **NC**: no paid access, no ad-gated or monetised downloads, no Patreon-only builds.
- **SA**: the port is released under CC BY-NC-SA 4.0 too.
- State the changes made (CHANGES.md).

Note: CC BY-NC-SA is not an OSI software licence and is incompatible with GPL/MIT code being mixed
in. Keep any third-party code out of the project unless its licence permits that.
